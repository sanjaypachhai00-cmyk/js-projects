# Tic Tac Toe

A browser-based Tic Tac Toe game built using HTML, CSS, and JavaScript.

## Features

* Two-player gameplay
* X and O turn system
* Win detection
* Draw detection
* Automatic game reset
* Manual reset button
* Responsive design
* Modern dark UI
* Red, yellow, and black color theme
* Winning cells are highlighted

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
tic_tac_toe/

└── README.md
```

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `tic.html` in a web browser.
4. Start playing.
## Game Rules

1. Player X starts the game.
2. Players take turns placing X and O.
3. The first player to get three matching symbols in a row, column, or diagonal wins.
4. If all nine cells are filled without a winner, the game is a draw.
5. After a win or draw, the game automatically resets.
